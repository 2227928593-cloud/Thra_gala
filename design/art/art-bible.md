## 1. 视觉锚点

### 1.1 一句话

> **一张 1932 年的橡皮管动画赛璐珞，被泡在 2000 年中国县城中学的福尔马林里。**

不是"美式卡通"，也不是"中式恐怖"。是**两种时代错误强行缝合**：画法来自大萧条前的美国动画，内容来自中国高考前夜的教室。缝合处就是恐怖发生的地方。

### 1.2 三个必须成立的矛盾（缺一个就失去风格）

| 矛盾 | 一边 | 另一边 | 为什么必须并存 |
|---|---|---|---|
| **A. 天真 vs 腐烂** | 圆头圆手、面条四肢、派切眼——"可爱"的语法 | 过长脖子、空眼眶、过大的笑、融化的墨——"尸体"的内容 | 只有可爱没有腐烂 = 儿童绘本；只有腐烂没有可爱 = 又一个暗黑游戏。恐怖来自**语法在说谎** |
| **B. 美国画法 vs 中国内容** | 1930s 墨线、白手套、橡皮管 | 校服、黑板、蹲厕、铁栏杆窗、黑长衫老人、尸斑 | 场景与服装**一律不美国化**。我们不画布鲁克林，我们画大昌市第七中学 |
| **C. 手绘的脏 vs 管线的齐** | 抖线、墨渗、错版、划痕 | 全 60 张同一地平线、同一暗角、同一光向 | 统一不等于干净。**误差必须是同一个误差**——同一支笔、同一个手抖频率 |

### 1.3 当前版本为什么被判定"简陋、不统一、割裂"（诊断）

| 现象 | 根因（已核对代码与资源） | 本圣经的解法 |
|---|---|---|
| 人物几乎不可辨认 | 立绘是**近黑剪影**（`portraits_sil.py`：INK `#08090b`），背景是**近黑场景**（`gen_scenes.py`：INK `#070a0b`），两者明度差 < 8%。再叠 `.sprite img{filter:brightness(1.22)}`，剪影内部仍无结构 | **反转明度关系**：人物以**骨白奶油**为身体主色、墨黑为线。人物是"亮纸片"，场景是"暗房间"。反差即识别度（详见 §6.2） |
| 同一人物不统一 | 每张立绘共用骨架函数，但**没有共用参考图**，参数各自漂移；`_eye`/`_marked`/`_dying` 是改代码分支重绘，不是 img2img | **母版 + img2img 谱系**：每族一张 style plate，所有成员以它为 `image1`；差分以本体为 `image1`（详见 §9.2） |
| 背景割裂 | 21 张各自构图，地平线高度、灭点、暗角强度不一致；`_rot` 是**后期叠加**（`gen_rot.py` 压暗+霉斑），与本体不是同一条线，接缝可见 | **同一张底稿谱系**：统一地平线 62%、统一灭点、统一光向；`_rot` 改为**同一条墨线管线的重渲染**（腐蚀版），不是滤镜（详见 §9.3） |
| 粗糙 | 几何盒子 + 中心光晕，没有笔触、没有墨渗、没有网点 | 全流程加**墨线层 / 网点层 / 纸纹层**，见 §8 |

## 2. 风格参照板

### 2.1 一级参照（决定画法）

- **Bendy and the Ink Machine** —— 取"橡皮管角色的恐怖扭曲"，**不取**其 3D 建模质感与黄黑配色。
- **Fleischer Studios / Betty Boop（1930–1934）** —— 取"会呼吸的背景"：家具、墙壁有轻微手绘弯曲，直线会微微弓。
- **Disney Silly Symphony · The Skeleton Dance (1929)** —— 取"用节奏与剪影讲恐怖"，不靠血腥。
- **1930s 美国剧场海报 / 罐头厂广告版画** —— 取"套色错位 + 粗描边 + 网点"的印刷错误感。

### 2.2 二级参照（决定内容，不决定画法）

- 2000 年代中国县城中学实景照片：水磨石地面、绿漆墙裙、铁栏杆窗、铝合金推拉门、双人木课桌、讲台粉笔槽。
- 《恐怖复苏》原文第 1–20 章的物件清单（黑长衫、尸斑、死灰眼、人皮纸、卫星电话、校服）。

### 2.3 明确禁止（看到即打回）

- 日式动漫脸、大眼高光、赛璐珞渐变头发
- 3D 渲染、PBR 材质、景深虚化
- 美式漫画交叉排线、硬阴影块
- 写实照片质感、真实皮肤毛孔
- 任何**图片内文字**（中文必糊；英文也不要，见 §7.4）
- 紫色/霓虹/赛博配色

## 3. 色板与十六进制

### 3.1 五色 + 一冷（硬限制，超出即违规）

| 角色 | 名称 | HEX | 说明 | 面积占比 |
|---|---|---|---|---|
| 线 | **墨黑 INK** | `#0C0B0A` | 所有轮廓、瞳孔、阴影核心。可加深至 `#050505` | 40–50% |
| 底 | **骨白 CREAM** | `#DCD0B4` | 人物身体、纸、墙面高光 | 30–38% |
| 中间调 | **褐 SEPIA** | `#6B4A2F`（深）/ `#A98A63`（中）/ `#C9B08A`（浅茶） | 阴影、木器、皮肤暗面、旧照片 | 10–18% |
| 强调 | **干血红 BLOOD** | `#8E1B18` / 亮 `#B33A2E` | 只用于：血、伤口、鬼眼、极少数"不对劲"的点 | **≤ 4%** |
| 唯一冷色 | **冷青 TEAL** | `#2F5F63` / 亮 `#6E9A94` | 只用于：**光源本体与受光边**（手机屏、走廊灯、门缝） | **≤ 2%** |
| 纸 | **纸底 PAPER** | `#E8DCC2` | 场景最亮面（墙面、天空、纸） | 仅场景 |
| 特赦 1 | **墨蓝 NAVY** | `#1E2A38` | **仅限**校服运动外套 / 塑料椅 / 铁制品的暗部。必须压到接近墨黑 | ≤ 10% |
| 特赦 2 | **墙裙绿 GREEN** | `#59684C` | **仅限**中国教室/走廊的 1.1 m 绿漆墙裙。必须低彩度、偏灰 | ≤ 12% |

> **两条特赦色的来历**：它们不是风格选择，是**内容事实**——2000 年代中国校服就是藏青，教室墙裙就是绿漆。取消它们，场景立刻不再是中国校园。但它们必须被压到"看起来像墨的蓝"和"看起来像灰的绿"，一旦鲜艳就出戏。已实测：现有 6 张锚定图的出格色占比 2–7%，全部合规。

> **冷青是本作唯一的冷色**（除上述两条特赦）。除此以外，全画面任何位置出现蓝、紫、绿、洋红，一律视为错误。这一点让"冷青 = 有光源 = 有活人/有出口"成为玩家可学习的视觉语法。

### 3.2 明度预算（关键，因为 CSS 会二次调色）

已核对 `css/style.css`：

```css
.bg      { filter: saturate(.95) contrast(1.1) brightness(1.04); }
.sprite img { filter: brightness(1.22) contrast(1.04); }
```

- **立绘**：内部最亮值**不得超过 `#CBBE9F`**。`0xCB × 1.22 ≈ 0xF7`，正好抬到"骨白将溢未溢"。若直接画到 `#F5EDDC`，进游戏会整片死白、丢失墨线。
- **场景**：按 **contrast 0.92、brightness 0.96** 的"预留位"作画（比目标观感低一档），让 CSS 的 `contrast(1.1)` 把它拉回。**不要在贴图里做过重的对比**，否则 `blood` 心情下 `contrast(1.14) brightness(.76)` 会把暗部彻底糊死。
- **血红在 `blood` 心情下会被 `hue-rotate(-16deg)` 推暖**，所以血要画成偏褐的 `#8E1B18`，不要画纯朱红 `#E00`——否则会被推到橙色，失去"干涸"感。

## 4. 线宽与笔触

### 4.1 线宽（按画布短边的百分比，不是绝对值）

| 层级 | 立绘 1024×1536 | 场景/结局 1536×1024 | 用途 |
|---|---|---|---|
| L0 外轮廓 | **7–11 px** | **9–14 px** | 整个剪影的边。**必须最粗**，橡皮管风格的骨架 |
| L1 主要结构 | 4–6 px | 5–8 px | 衣褶大形、门框、桌沿、窗棂 |
| L2 次要结构 | 2–3 px | 3–4 px | 扣子、拉链、砖缝、螺丝 |
| L3 排线/细节 | 1–2 px | 1.5–2.5 px | 皱纹、木纹、阴影排线、粉笔痕 |

> 换算：外轮廓 ≈ 短边 × **0.7%–1.1%**。这条公式在后续任何分辨率都成立。

### 4.2 笔触规则（"脏"必须是被设计出来的）

1. **压力抖动**：线宽沿途变化 ±35%，周期 40–60 px。
2. **收笔渐细**：每一笔两端 40% 长度内线宽渐收至 30%。
3. **起笔墨点**：约 20% 的线在起笔处留一个 1.5–2× 线宽的墨结。
4. **直线要弓**：任何"应该笔直"的线（门框、桌沿、地平线）**弓 0.3%–0.8% 长度**，弓向随机但同一张图内一致。这是 Fleischer 背景的核心特征——画面在呼吸。
5. **墨渗**：粗线外侧 1–2 px 的 8–15% 黑晕，模拟蘸水笔在粗纸上的洇开。
6. **不闭合**：约 15% 的结构线在转角处**留 2–4 px 缺口**，不追求闭合。闭合 = 矢量感 = 廉价。

### 4.3 填色规则

- **平涂**，不做渐变（渐变只能出现在光照衰减区，且用 2–3 段阶梯代替连续过渡）。
- 阴影用**同色相降明**（cream → sepia），不引入新色相。
- **网点（halftone）**用于过渡：45° 网角，cell 3 px（1536 宽）/ 2 px（1024 宽），覆盖率 8–18%，**只出现在明暗交界处**，不铺满。

## 5. 光照与构图

### 5.1 光照（全片唯一一套）

| 参数 | 值 |
|---|---|
| 主光方位 | **左前上方**，方位角 315°，仰角 35° |
| 主光色温 | 骨白（`#DCD0B4`），强度 100% |
| 补光 | **无**。暗部不加补光，直接落 sepia → 墨黑 |
| 轮廓光 | 右后上方，**冷青 15%**，仅勾 2–4 px 边缘 |
| 环境光 | 极低（5%），冷青偏褐 |
| 底部光 | **禁止**。任何从下往上的光都读作"舞台灯"，破坏 1930s 感 |

> 立绘与场景**共用同一光向**。人物如果是右前方打光，背景是左前上方，两者就会"贴不到一起"——这是当前版本割裂感的主要来源之一。

### 5.2 立绘构图模板（11 张必须逐像素对齐）

画布 `1024 × 1536`（2:3），透明背景：

```
y=0     ┌────────────────────────┐
        │                        │  头顶留白 4.5%
y=22%   │        ◯ 眼线 338px    │  ← 全族统一 22%，误差 ≤ 1%（v1.2 定案）
        │      (头部中心 x=46%)   │     头宽 ≈ 30% 画布 = 307px
y=39%   │      ╱ 肩线 599px      │  ← 全族统一
        │     ████               │     身体占 x 18%–84%
        │     ████               │     面向左，脸前留白 ≥ 10%
y=78%   │     ████  ← CSS 渐隐起 │  ← 关键信息（手、道具、伤口）必须高于此线
y=96%   │     ████               │     画面到底，不画脚
y=100%  └────────────────────────┘
```

**为什么 78% 是死线**：`css/style.css` 的 `.sprite img` 有
`mask-image: linear-gradient(180deg,#000 78%, rgba(0,0,0,.55) 94%, transparent 100%)`。
78% 以下开始半透明，94% 以下基本消失。**任何"要玩家看清"的东西放在 78% 以下等于没画。**

### 5.3 场景构图模板（21 张 + 7 结局）

画布 `1536 × 1024`（3:2）：

| 锚点 | 值 | 容差 |
|---|---|---|
| 地平线 | **生成稿 y = 62%（635/1024）**；裁到 16:9 后落在 **64.2%** | ±2% |
| 单点透视灭点 | x = 50%，y = 与地平线相同 | x ±6% |
| 主光方向 | 左上（同 §5.1） | 0 |
| 暗角 | 四角 −38%（烘焙），叠 CSS 的 `−86%` | ±5% |
| 安全区 | **x 15–85%、y 10–90%** | 硬约束 |

**安全区为什么这么定**：`.bg{ object-fit: cover }` 在 16:9 视口裁掉上下各约 7.8%；手机竖屏会裁掉两侧 40% 以上。落在安全区外的只允许是"可牺牲的装饰"（天花、地面纹理、边角杂物），**不允许是门、脸、血、光源**。

> ✅ **已定案（族锚定实测后）**：场景**一律 1536×1024 生成，再居中裁到 1536×864（16:9）**。
> 理由有二：① 16:9 是引擎舞台的真实比例，零拉伸；② **裁掉的 7.8% 正好是水印所在的那条带**，水印被几何清除，不需要修补、不留补丁痕迹。
> 代价是上下各裁 80 px，所以安全区（y 10–90%）是硬约束——裁掉的部分只允许是可牺牲装饰。
> 3:2 母版保留在 `art/_src/`，供未来竖屏/宽幅移植。

### 5.4 空的语法（场景的恐怖来自"少了什么"）

- 每张场景**人物数量 = 0**（`classroom_ghost` 允许 1 个剪影，且不画五官）。
- 椅子**必须推进桌下**，只允许 0–1 把拉出（`classroom` 用 1 把，制造"刚有人离开"）。
- 光源**不超过 2 个**，其中 1 个必须是冷青。第三个光源 = 失去焦点。
- 血**最多 1 处**，面积 ≤ 画面 3%，位置永远在**视觉动线的终点**（走廊尽头、黑板下沿、门内侧），不在画面边缘。

## 6. 角色视觉语言

### 6.1 头身与解剖（橡皮管规则）

| 项 | 规则 |
|---|---|
| 头身比 | **4.5–5 头身**（不是写实 7.5，也不是 Q 版 2） |
| 头形 | 略呈**上宽下窄的蛋形**，下颌线一根弧完成，不画颧骨与咬肌 |
| 四肢 | **无肘、无膝关节**。整条手臂是一根**等粗、带 2 处缓弯的橡皮管**，靠弯曲幅度表达动作 |
| 手 | 四指（不是五指），戴**白手套**（学生角色也戴——这是风格契约，不是剧情道具）；手套只用一根墨线分割手指，不画指甲 |
| 眼 | **派切眼（pie-cut）**：眼睛是切掉一块的椭圆/楔形，黑色实心或白色底 + 1 个黑点瞳孔。**禁止**画虹膜纹理、睫毛、高光十字 |
| 脖 | 比正常长 **15–25%**（恐怖预算的主要支出项） |
| 重心 | 单肩下沉 ≥ 3% 头高，**不允许左右对称站姿** |

### 6.2 识别度装置：**骨白切边（Cream Keyline）** ← 本方案的核心发明

**问题**：暗场景 + 黑长衫 = 人物消失（当前版本正是如此）。
**解法**：所有立绘的**整体剪影外圈加一条 6 px 的骨白切边**，色值 **`#A89670`**（v1.2 终值；早期 `#CBBE9F` 经 CSS `brightness(1.22)` 会提成近纯白，读作贴纸边，已废弃）。

效果：人物读作**从旧海报上剪下来的纸片木偶**，边缘永远与暗背景分离。它同时是风格理由（1930s 剪纸/赛璐珞）与技术理由（可读性）。**这一条承担了全作 80% 的"人物可辨认"责任。**

- 切边宽度**全族一致，固定 6 px**。`clean_watermark.py` 的 `rebuild_keyline()` 用『先腐蚀 8px、再补 6px』实现，宽度与色值完全确定，不依赖模型。
- 切边**不进入剪影内部**（不勾内部分割线）。
- 若某角色通体极暗（老人、鬼婴），切边加宽至 **10 px**，并在暗部内部加 **1 条 sepia 内部亮线**提示体积。
- ⚠️ 样张 `laoren.png` 的切边偏白偏粗（≈12 px、近纯白），看起来像贴纸。**批量时收到 8 px / `#CBBE9F`**。

### 6.3 恐怖预算（每张立绘只能花 2 项，花 3 项就变成怪物展览）

可选扭曲项：`过长脖` / `空眼眶` / `过大的笑` / `融化滴墨` / `多一只手指` / `关节反向` / `皮肤下的凸起` / `不对称瞳孔`。

- **人类角色：1–2 项**（杨间=0 项，靠眼神；张伟=1 项；方镜=2 项）。
- **鬼：2–3 项**（老人=过长脖+空眼眶+融化墨；鬼婴=全项）。
- **恐怖是稀缺资源**：全班 11 张里，只有 3 张允许"明显不正常"。其余越正常，那 3 张越可怕。

## 7. 环境视觉语言

### 7.1 五类场景的语法

| 类型 | 场景 | 透视 | 空间感来源 | 专属元素 |
|---|---|---|---|---|
| **教室类** | classroom, classroom_early, classroom_ghost, classroom_after | 单点，灭点在黑板中线 | 成排课桌的重复节奏 | 绿黑板、粉笔槽、吊灯管、后门 |
| **走廊类** | corridor_dark, corridor_2f, stairwell, stairwell_mirror | 单点，灭点在纵深尽头 | 门窗等距 + 地砖缝 | 绿色墙裙（高 1.1 m）、铁栏杆、水磨石 |
| **小空间** | toilet, guard_booth, morgue, hospital, room_night | 一点/两点，俯角 5–10° | 物件拥挤与遮挡 | 蹲位隔断、监控屏、铁床、塑钢窗 |
| **室外** | school_gate, playground, woods, street_day, street_night, street_dawn | 两点或平视 | 地平线 + 重复的树/栏杆 | 电动伸缩门、篮球架、梧桐、卷帘门 |
| **超现实** | void_dark, bone_tree | 无透视（纯黑场）/ 仰角 | 光源距离与颗粒 | 唯一的一束冷青、白骨树+倒挂黑影 |

### 7.2 中国校园的硬约束（不许美国化）

- 窗：**铁栏杆**（竖条 + 中间横档），铝合金框，不是格子窗。
- 墙：下半 **1.1 m 绿色墙裙**，上半米白，交界处一条深绿线。
- 地：**水磨石**（灰白底 + 黑石子），不是木地板。
- 门：上部带一块玻璃的**木门/铁皮门**，门把手是下压式长柄。
- 桌：双人**木课桌**，桌面有刻痕与修正液白斑（**不许是文字**）。
- 灯：**单/双管日光灯**吊链悬吊，其中一支必须接触不良（半亮/闪）。
- 黑板：绿色，粉笔槽有粉笔头与板擦印。

### 7.3 腐化梯度公式（决定 `_rot` 有多烂）

按剧情时间（晚 21:47 → 凌晨 5:31），同一地点的腐化度**单调递增**：

| 阶段 | 触发 | 视觉 |
|---|---|---|
| R0 原貌 | 第一幕前段 | 干净，仅颗粒与暗角 |
| R1 潮湿 | 第一幕末（p17） | 墙角水痕、纸皮起翘、灯光偏冷 |
| R2 剥落 | 第二幕楼梯/走廊 | 墙皮掀起露出灰浆、地砖错位、门框歪 2–3° |
| R3 霉变 | 第二幕厕所/黑暗 | 大面积霉斑、天花板下垂、墨从缝里渗 |
| R4 溶解 | 第三、四幕 | 结构线开始"化"，家具边缘变软、地板出现墨池 |

> `_rot` 必须体现**至少 2 级的差值**，但不能改变构图、灭点与光向——玩家要能认出"还是那间教室，只是它老了三十年"。

### 7.4 文字禁令（硬性）

**图片内不得出现任何文字，中英文数字全禁。** 理由：
1. 中文在生成模型里必然糊成伪字，廉价感极强；
2. 台词由引擎叠加（`.dialogue`），图内文字会与 UI 争抢注意力；
3. 场景里的文字会锁死叙事（玩家会去读、去推理不存在的线索）。

黑板/告示栏/书本/门牌的处理方式：
- 黑板 = **抽象粉笔痕**：3–6 条弧形擦痕 + 2–3 团尘团 + 一条下沿的粉笔灰堆积。**只有笔势，没有字形。**
- 告示栏 = 若干**空白纸片**（不等大的四边形，边缘卷曲）。
- 门牌 = 一块**空牌**，只用 1 条墨线表示边框。
- 若模型仍写出字：**重跑或局部修补**，不接受"看起来像字的装饰"。

## 8. 后期与统一 LUT

### 8.1 管线顺序（不可调换）

```
AI 生成底稿 (场景 **只允许 1536×1024** / 立绘 1024×1536)
       ★ 硬规范：16:9（1536×864）是**交付尺寸，不是生成尺寸**。
         直接用 1536×864 出图会把水印留在画内，必须修补；
         用 3:2 出图再裁到 16:9，水印所在的底部条带被整体裁掉，零痕迹。
 → ① tools/clean_watermark.py
       · 场景：居中裁到 16:9 —— 裁掉的正是水印所在的底部条带（几何清除，零痕迹）
       · 立绘：棋盘格 flood fill → 真 alpha；再按色相签名补掉人物内部封闭的棋盘格块
 → ② 结构修补（补断线、合并错位轮廓、眼线对齐到 22%）
 → ③ tools/lut.py --preset clean ：曲线 / 色相锁定 / 0.5px 套色偏移
 → ④ 纸纹 multiply 8%          ┐
 → ⑤ 网点 12%（cell 3px / 45°）  │  tools/lut.py --preset full
 → ⑥ 胶片颗粒 4%（overlay）      │  （强度上限见 §8.2，默认只补一半）
 → ⑦ 放映机划痕 1–2 条           │
 → ⑧ 暗角 38%（径向，中心 0）    ┘
 → ⑨ 导出 sRGB 8bit，无 ICC，无 EXIF
```

> 两个脚本已落地：`tools/clean_watermark.py`（含 `--dry-run`，对比图出到 `art/_samples/_clean_preview/`）、`tools/lut.py`（含 `--check` 色板审计）。
> 实测结论：**`background:transparent` 拿不到 alpha**——模型返回的是"画出来的棋盘格"，全图 alpha=255。所以立绘必须走 keying，不能指望它自己透明。

### 8.2 与既有 CSS 后期的共存（**最容易翻车的一节**）

`css/style.css` 已经在运行时叠加了：颗粒 `.fx-grain` 10.5%（overlay）、扫描线 `.fx-scan` 16%、暗角 `.fx-vignette`（四角至 86%）、`body::after` 全局颗粒 5.5%、`bg-fog` 24%、`bg-tint` 顶部 30%/底部 78%。

**因此烘焙进贴图的后期必须"减半再减半"**：

| 效果 | CSS 已有 | 贴图内允许烘焙 | 说明 |
|---|---|---|---|
| 颗粒 | 10.5% + 5.5% | **≤ 4%** | 再高就成雪花屏 |
| 扫描线 | 16% | **0%** | 绝对不要烘焙扫描线 |
| 暗角 | 至 86% | **≤ 38%** | 双重暗角会让画面中心也发灰 |
| 雾 | 24% | ≤ 10% | 雾只做空气透视，不做氛围 |
| 对比 | contrast 1.1（可到 1.14） | 按 0.92 作画 | 留出抬升余量 |

> **验收方法**：把贴图直接贴到 `#0a0a0a` 背景、不加任何 CSS，观感应是"偏平、偏亮、有点脏"——这是对的。进游戏后才是最终观感。

### 8.3 统一 LUT 具体参数

- **曲线**：黑场抬到 RGB 6，白场压到 96%（保护墨线不死黑、纸不死白）。
- **色相锁定**：把全图色相向 5 个锚点吸附（18°/32°/38° sepia、0° blood、186° teal），偏离 > 25° 的像素降饱和 60%。
- **套色偏移**：红色通道右移 0.5 px、青色通道左移 0.5 px。**全族方向一致**（统一右移，不要随机——错版要错得一样）。
- **锐化**：无。宁可软，不要数码锐化。
- **禁止**：HDR、色调映射、发光（bloom）、色差（chromatic aberration）——全部属于 2010s 数字观感，与 1932 冲突。

### 8.4 `_rot` 的重渲染（不再用 `gen_rot.py` 后期叠加）

旧做法（`tools/gen_rot.py`：压暗 + 霉斑 + 水痕叠加）问题：亮度曲线与本体不同源，两张图切换时"色温会跳"。

**新做法**：
1. 以本体最终图为 `image1`，`input_fidelity 0.72`；
2. 提示词 = 本体的提示词 + **腐化后缀**（`the same room decades later: paint peeling in sheets, black mold spreading from the ceiling corners, water stains running down the wall, rust on every metal edge, ink seeping from the seams, furniture edges going soft, ceiling sagging`）；
3. **保持**：构图、灭点、光向、地平线、物件位置全部不变，只改材质与腐化；
4. 出口 LUT 与本体**同一条**（走同一份 `lut.cube`），只把暗角 +8%、颗粒 +2%。

验收：把本体与 `_rot` 叠图做差值，**结构边缘应重合**（差 ≤ 6 px）；不重合说明模型改了构图，必须重跑。
